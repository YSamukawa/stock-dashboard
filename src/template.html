設定

データはブラウザから Twelve Data API を直接呼び出します（無料プラン: 8クレジット/分・800/日）。キーは twelvedata.com で無料登録して取得し、このブラウザの localStorage にのみ保存されます。
APIキーに MOCK と入力すると合成データでUIを試せます。
目安: 10銘柄+ベンチマークの時系列で11クレジット。ファンダ込みで約41クレジット（分あたり上限のため初回は数分かかります）。

TradingView CSV 取込（ローカルのみ）

TradingViewの「チャートデータをエクスポート」で保存したCSV（time,open,high,low,close,…）を取り込みます。データはこのブラウザのIndexedDBにだけ保存され、GitHubにも外部にも送信されません。ファイル名 BATS_AVGO, 1D_xxxx.csv から銘柄を自動判定します。
